Directory SWHIDs include executable bits and symlink modes. A file's content SWHID covers only its bytes; a symlink's content is its target path, not the target file.

TAR stores modes directly. ZIP needs Unix mode metadata in its external attributes. Some Windows-built wheels and source distributions omit it; this app rejects those archives rather than guessing. Other extraction tools can assign different modes and produce different directory SWHIDs.

Paths with the same content SWHID contain identical bytes. The repeated-path count excludes the first path in each group. Executable modes can differ; symlinks compare their target bytes.
